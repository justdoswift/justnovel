网页小说 装订成书

下载 macOS 版 ↗

连载在网页上，读起来却像网页：广告、分页、随时消失的章节。 JustNovel 把整本书抓下来，排成一本带目录和封面的 EPUB， 存进你的 Downloads，从此离线可读。

支持 69 书吧 飘天文学 思兔 sto9

01 / 怎么用

四步，从书名到一本书。

没有导入、没有账号、没有云端队列。搜索、下载、导出都在一个窗口里。

01

选站点

69 书吧、飘天文学、思兔 sto9，三个站点各查各的。

02

搜书名

输入书名回车。站点要验证时，浏览器面板会自己出现。

03

下载

点一本书，读出目录，点开始下载。逐章抓取，可随时暂停。

04

导出

完成后自动存到 Downloads，也可以手动导出部分 EPUB。

02 / 能力

为长篇连载做的细节。

不是通用爬虫，也不是阅读器。只处理一件事：把一本书完整地拿下来。

搜索
三个站点各有各的搜索规则：飘天文学要 GBK 编码，思兔用 POST 表单，69 书吧在 Cloudflare 后面。前两个直接请求就回结果，被拦时才开浏览器。
会话
内嵌真实浏览器，过掉 Cloudflare 验证后把 HTTPOnly Cookie 交给抓取器。目录和正文都走同一个会话。
续传
暂停、继续、跳过失败章节、从头重下。每 50 章落盘一次，意外退出也能从历史记录导出。
回退
章节请求被拦截时自动回退到浏览器抓取，限流按站点节奏等待重试。
EPUB
EPUB 3，可选正文字体、首页说明、来源链接和 PNG / JPEG / WebP 封面。
原生
Go + MyGo 原生界面，单窗口；没有 Electron，没有内置服务器。菜单里可以检查更新。
03 / 构建

从源码构建。

项目只依赖 Go 与 MyGo，没有 Node 构建链。克隆后直接用 go tool mygo 开发或打包。

MyGo 会生成 .app 和 dmg，前端资源嵌在可执行文件里。打包时用本机的密钥签名，装好的 app 可以自己检查更新。

  • go 1.27+
  • macOS 13+
  • MIT License
terminal 
# 克隆并进入项目
git clone https://github.com/justdoswift/justnovel.git
cd justnovel

# 开发：改 Go 代码后自动重启
go tool mygo dev

# 打包到 build/darwin-arm64/
go tool mygo build
open build/darwin-arm64/JustNovel.app
