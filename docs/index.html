WEB NOVEL
→ EPUB

打开目录页，在浏览器里过掉站点验证，批量下载章节，导出带目录和封面的 EPUB。为长篇连载准备的 macOS 抓取工作台。

> 69 书吧 / 飘天文学 / 思兔 sto9

01 / FLOW

三步，从目录页到 EPUB。

没有导入、没有账号、没有云端队列。地址、验证和章节都在一个窗口里。

01 PASTE

粘贴目录页地址

自动识别 69 书吧、飘天文学或思兔 sto9，站点选择和地址不会再对不上。

02 VERIFY

在浏览器里完成验证

内嵌真实浏览器会话；过掉站点验证后同步 Cookie，目录和正文都走这个会话。

03 EXPORT

下载并导出

顺序抓取章节，随时暂停、继续或跳过失败章节；导出 EPUB 3，带目录、字体、首页文案和封面。

02 / CAPABILITIES

为长篇连载做的细节。

不是通用爬虫，也不是阅读器。只处理一件事：把一本书完整地拿下来。

SOURCES
69 书吧、飘天文学、思兔 sto9，地址自动归一化到完整目录页，避免只抓到最新章节。
SESSION
内嵌浏览器完成 Cloudflare 验证，HTTPOnly Cookie 同步给抓取器。
RESUME
暂停、继续、跳过失败章节；每 10 章落盘一次，意外退出也能从历史记录导出。
FALLBACK
章节请求被拦截时自动回退到浏览器抓取，限流按站点节奏等待重试。
EPUB
EPUB 3，可选正文字体、首页说明、来源链接和 PNG / JPEG / WebP 封面。
NATIVE
Go + MyGo 原生界面，单窗口；没有 Electron，没有内置服务器。
03 / BUILD

从源码构建。

克隆后直接用 go tool mygo 开发或打包；MyGo 会生成 .app 和 dmg，前端资源嵌在可执行文件里。

项目只依赖 Go 与 MyGo，没有 Node 构建链。克隆后直接用 go tool mygo 开发或打包。

  • go 1.27+
  • macOS 13+
  • MIT License
terminal
# 克隆并进入项目
git clone https://github.com/justdoswift/justnovel.git
cd justnovel

# 开发：改 Go 代码后自动重启
go tool mygo dev

# 打包到 build/darwin-arm64/
go tool mygo build
open build/darwin-arm64/JustNovel.app
04 / OPEN SOURCE

代码在 GitHub 上。

解析器、抓取策略、EPUB 生成和界面都在一个 Go 模块里；欢迎提 issue 或 PR。
