# JustNovel

JustNovel 是一个 macOS 桌面应用，用来把公开的网页小说抓取下来，整理成带目录的 EPUB，方便离线阅读。

它用 [MyGo](https://mygo.egoist.dev/) 写成：界面是 Go 绘制的原生 UI，需要时内嵌一个真实的浏览器会话，用来通过站点的 Cloudflare 验证，并把 Cookie 交给抓取器使用。

## 功能

- 支持 69 书吧、飘天文学、思兔 sto9 三个站点
- 一个输入框：输入书名回车搜索，粘贴书籍页/目录页/章节页地址回车直接打开。地址属于哪个站点就自动切过去
- 搜索先走普通 HTTP 请求，被拦截时才打开浏览器面板，让人工验证一次
- 自动把书页/章节页地址规范化为完整目录页
- 顺序下载章节，遇到限流自动等待重试，被拦截时回退到浏览器会话抓取
- 支持暂停、继续、跳过失败章节、从头重下、停止并保留历史
- 导出 EPUB 3：可选正文字体、首页说明、来源链接和封面（PNG/JPEG/WebP）
- 下载历史：保存已抓取的章节，可随时重新导出，无需再次访问站点
- 下载完成后自动保存到 Downloads；也可以手动导出部分 EPUB
- 下载进度按章节数与时间落盘，意外退出后仍可从历史记录导出已完成部分

## 开发

需要 Go 1.27 或更高版本（项目通过 `go tool mygo` 使用 MyGo CLI）。

```sh
go tool mygo dev     # 启动开发版本，修改 Go 代码后自动重启
go test ./...        # 解析、抓取、EPUB、状态机与端到端测试
go tool mygo build   # 打包到 build/darwin-arm64/
```

`SHOOT=1 go test -run TestShootStates` 会把窗口的每个状态渲染成 PNG 写到 `.oil-ui/shots/`，不用启动应用就能看设计。

## 使用

1. 在左侧栏选站点（69 书吧 / 飘天文学 / 思兔 sto9）。
2. 在顶部搜索框里输入书名回车，或者粘贴书籍页/目录页地址回车。站点要验证时，浏览器面板会自己出现，完成验证即可。
3. 在结果里点一本书，目录会自己读出来。
4. 点工具栏的「开始下载」，可随时暂停、停止或继续。
5. 下载完成后自动保存到 Downloads；也可以随时「导出当前内容」生成部分 EPUB。

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `main.go` | 应用启动、窗口与菜单 |
| `model.go` | 数据模型，以及 `Phase`：应用唯一的状态真相 |
| `session.go` | `Session`：站点、书、下载、阶段。所有状态迁移都在这里 |
| `session_actions.go` | 打开、搜索、下载、暂停、停止等动作 |
| `download.go` | 下载循环，入参是一个 `Job` 值，不读 UI 状态 |
| `export.go` | 导出流程与保存对话框 |
| `app.go` | 窗口状态：哪个对话框开着、列表选中什么 |
| `view.go` | 原生 UI 的布局与样式 |
| `panel.go` | `Panel` 接口：会话使用浏览器的方式 |
| `browser.go` | 内嵌浏览器：Cookie、页面快照、浏览器回退 |
| `sources.go` | 站点定义、目录页 URL 规范化与搜索入口 |
| `search.go` | 三个站点的搜索结果解析 |
| `search_direct.go` | 不带浏览器的搜索请求 |
| `log.go` | 执行日志 |
| `adapters.go` | 三个站点的目录/正文解析 |
| `crawler.go` | HTTP 抓取、限流重试、编码识别、浏览器回退 |
| `parse.go` | HTML 清洗与文本规范化，正则预编译 |
| `epub.go` | EPUB 3 生成 |
| `history.go` | 历史记录：`index.json` + 每本一个文件 |

### 状态机

`Phase` 是唯一真相。`Busy()`、`CanPause()`、`CanResume()`、`CanStart()`、`CanExport()` 全部从它派生，没有任何可独立赋值的布尔。0.1.1 里"正在读目录"和"忙不忙"由两处各自判断、标准不一致，导致粘贴链接后永远停在"正在读取目录…"；现在只有一处判断。
